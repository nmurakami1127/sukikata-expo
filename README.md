# スキかた – タイマー & Before/After撮影フロー（Expo Go 確認用）

タイマー機能にBefore/After撮影を組み込んだ画面遷移を、実機のExpo Goでそのまま確認できる形にしたものです。

## 動作環境について
2026年7月現在、Expo Go（実機アプリ）が物理端末で対応しているのは **Expo SDK 54** です
（SDK 55以降はApp Store側の審査待ちのため、実機確認にはSDK 54を推奨します）。
このプロジェクトはSDK 54を前提にしています。

## セットアップ手順

```bash
# 1. このフォルダに移動して依存関係をインストール
cd sukikata-expo
npm install

# 2. カメラ撮影・触覚フィードバック・タイマーリング表示に使う追加パッケージを、
#    SDK 54と互換性のあるバージョンで自動インストール
npx expo install expo-image-picker expo-haptics react-native-svg

# 3. 開発サーバーを起動
npx expo start
```

ターミナルにQRコードが表示されるので、スマホの **Expo Go** アプリでスキャンしてください
（iOSはカメラアプリからスキャン→Expo Goで開く、Androidは Expo Go アプリ内のQRスキャナーから）。

実機でカメラを使うため、**シミュレーター/エミュレーターではなく実機での確認を推奨**します
（シミュレーターではカメラが使えず撮影ステップでエラーになります）。

## 確認できる流れ（指示書 2-3 準拠）
1. タスク画面 →「5分、はじめる」
2. 撮影前ステップ：「撮影する（カメラ起動）／スキップ」
3. 5分タイマー（「完了した」でいつでも終了可）
4. タイマー終了 →「まだやる／ここで終わる」
5. 撮影後ステップ：「撮影する／スキップ」
6. 完了画面：褒めメッセージ＋Before/Afterの写真をシンプルに並べて表示
7. タスク画面の「今日はここまで（写真だけで完了）」→ 写真1枚（またはスキップ）だけで完了扱いにする救済導線

## 実装メモ
- 撮影は `expo-image-picker` の `launchCameraAsync` でカメラを直接起動。フィルターや比較スライダーは実装していません（仕様通り）。
- 写真は端末内のURIをその場で保持しているだけで、外部送信は一切行っていません。本番実装では `expo-file-system` で `documentDirectory` 配下に永続コピーする想定です（クラウド同期は不要という仕様のまま）。
- タイマー終了時は `expo-haptics` の通知フィードバックで振動を再現しています（実機のみ動作、シミュレーターでは反応しません）。
- 色は指示書5-1のパレット、褒めメッセージは指示書6-5のリストからランダム表示しています。
